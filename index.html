01 / PYTHON

用Python记录和处理一批结果

变量给一个值起名字；列表保存一组有顺序的值；字典用“键”查找对应值。缩进告诉Python哪些语句属于同一个代码块。

可运行：Python标准库，不依赖数据集
scores = [0.12, 0.81, 0.45, 0.92]
threshold = 0.50

def decide(score, limit):
    if score >= limit:
        return "报警"
    return "放行"

for index, score in enumerate(scores):
    print(index, score, decide(score, threshold))

输出的编号从0开始。0.81和0.92达到阈值，输出“报警”。这里的数字是教学示例，函数中的return把结果交回给调用它的地方。

怎样动手：打开记事本，把上面的代码保存为practice_python.py；在该文件所在目录的PowerShell中运行python .\practice_python.py。复制时不要把页面上“可运行”说明一并复制到文件里。
练习1：把阈值改为0.8，会有几个“报警”？

两个：0.81和0.92。条件是大于或等于阈值；如果有0.80，也会报警。

练习2：为什么不能把四个分数的平均值直接称为准确率？

02 / MATH

向量、平均值和梯度：先会解释

一个向量可以看成一串有顺序的数。设a=[1,2]、b=[3,4]，点积是1×3+2×4=11。模型里的特征和权重经常用向量或数组表示。

平均值描述一组数的平均水平，标准差描述它们围绕平均值的波动。多次实验的均值与波动应一起看；三个种子只能初步观察波动，不能自动保证结论显著。

梯度与学习率

假设模型预测ŷ=w×x，给x=2、目标y=4，损失L=(ŷ−y)²。初始w=0时L=16。此时对w的梯度为−16；学习率取0.1，更新w=0−0.1×(−16)=1.6，新预测为3.2，损失为0.64。这个例子只调整一个参数，目的是看懂更新方向。

参数新值 = 参数旧值 − 学习率 × 梯度

偏导数可以理解为：其他变量暂时固定时，某个变量变化会怎样影响结果。神经网络有很多参数；反向传播借助链式法则计算各参数的梯度，优化器再按规则更新。你暂时只需能解释方向与步幅。

练习：a=[2,1]、b=[3,−1]，点积是多少？

2×3+1×(−1)=5。

03 / ARRAY

把图片当作一个有形状的数字盒子

NumPy数组和PyTorch张量都能表示多维数字。形状shape告诉你每个方向有多少个数。以RGB图片为例，常见读取顺序是高H×宽W×通道C；PyTorch模型经常用批数N×通道C×高H×宽W。

可运行：需要NumPy
import numpy as np

a = np.array([[1, 2, 3], [4, 5, 6]])
print(a.shape)          # (2, 3)：2行3列
print(a[0, 1])          # 2：第0行第1列
print(a.mean())         # 3.5
print(a.mean(axis=0))   # 每列平均：[2.5 3.5 4.5]

索引从0开始。axis=0对第0个维度计算平均，所以这里得到每列的平均。输入RGB图片到模型前，应核对颜色顺序、形状、数据类型和数值范围；同样叫“归一化”，不同实现也可能使用不同公式。

张量练习：一批4张320×320的RGB图片，采用NCHW顺序时，形状是[4,3,320,320]。如果第一维变成1，表示一次只处理一张图。
练习：形状[2,3,10,20]的N、C、H、W分别是什么？

N=2、C=3、H=10、W=20。它可表示2张、每张3通道、高10宽20的数据。

04 / IMAGE

相机图片和模型输入之间发生了什么？

光源照到工件，表面反射光经过镜头，被传感器转换为数字。光源角度、曝光、增益、反光和工件位置会改变成像。一张8位灰度图片的像素常为0—255；其他数据可能采用不同位深。

光源与工件→镜头、传感器→颜色/格式转换→缩放与归一化→模型输入

OpenCV常见的彩色读取顺序为BGR，许多模型或可视化流程使用RGB；具体以代码为准。一个常见转换为cv2.cvtColor(image, cv2.COLOR_BGR2RGB)。应先检查读取是否成功，再访问图片形状。

可运行：需要NumPy和OpenCV；合成图片，无需相机
import numpy as np
import cv2

bgr = np.zeros((2, 3, 3), dtype=np.uint8)
bgr[0, 0] = [255, 0, 0]  # BGR：这个像素是蓝色
rgb = cv2.cvtColor(bgr, cv2.COLOR_BGR2RGB)
print("形状:", rgb.shape)       # (2, 3, 3)
print("转换后:", rgb[0, 0])    # [0 0 255]，RGB中的蓝色

一条划痕在原图只占几像素时，缩小图片可能使它模糊。先可视化缩放后的图片，再比较不同输入尺寸的召回与运行成本。

练习：在电脑上把图片亮度乘0.6，能完全代替真实降低曝光吗？

不能。它适合做可控的数字扰动；真实曝光还可能改变噪声、饱和和反光，应另做相机采集验证。

05 / DATA

分类、检测、分割各需要什么标签？

任务问题常见标签
分类图片有没有缺陷？整张图的类别。
目标检测缺陷在哪里、属于哪类？类别和矩形框。
分割具体哪些像素属于缺陷？像素级掩码。
正常样本异常检测哪里偏离正常外观？常见设置以正常图训练；测试要有评价标签。

训练集用于更新参数；验证集用于开发阶段选择配置；测试集用于方案确定后的评价。同一工件的连续帧若混入不同集合，结果可能偏乐观，应考虑按工件/批次分组。

增强是在训练中产生合理变化，例如允许范围内的亮度或翻转；先划分再对训练集增强。是否允许旋转取决于任务：具有方向要求的工件，旋转可能改变标签含义。

本机已有数据：NEU-DET课程项目包含1800张图像，使用自建1260/270/270训练、验证、测试划分；它不是官方统一划分。项目做过重复图片分组和标注检查。正式论文比较仍要检查对方划分和评价条件。
练习：同一个零件连续拍摄20帧，能否把前10帧训练、后10帧测试？

这样很容易让测试图与训练图过于相似。更可靠的起点是按零件或采集批次分组，保证测试对象独立。

06 / TRAIN

模型为什么能从错误中改进？

样本和标签→前向预测→损失函数→反向传播→参数更新

模型是带参数的函数。前向根据当前参数得到预测；损失函数衡量训练目标上的偏差；反向传播计算损失对参数的梯度；优化器按学习率等设置更新参数。

一轮epoch通常指遍历一次训练集。batch是每次同时处理的一批样本；例如100张图、batch20、不丢最后一批，一轮5次更新。最后一批不满、梯度累积或重复采样时，更新次数可能不同，应该查看实际代码和日志。

过拟合是对训练数据拟合得较好，但对未见样本的表现不理想。可以同时观察训练和验证曲线，检查泄漏、数据代表性与模型复杂度；仅看训练loss下降不足以证明泛化。

训练阶段与推理阶段不同。PyTorch的train()和eval()会影响如BatchNorm、Dropout等层；评价时还要用no_grad()等关闭梯度记录。具体行为以代码为准。
练习：loss从0.8降到0.2，就能说测试准确率一定提高了吗？

不能。它只说明记录的训练损失下降；测试表现要按预先固定的评价流程测量。

07 / CNN

卷积怎样把局部数字变成特征？

卷积可以想成小窗口在图像上移动，每个位置做乘法和加法。不同权重对局部图案产生不同响应；多层网络把局部响应逐步组合起来。

局部图片：[[1, 2], [3, 4]] 权重： [[1, 0], [0, -1]] 乘加结果：1×1 + 2×0 + 3×0 + 4×(-1) = -3

这里只演示一次乘加，不代表−3就是缺陷。通道可以理解为一组特征图；步幅决定窗口每次移动多少；填充是在边界补值以控制输出形状。下采样缩小特征图，可能减少计算，也可能损失微小缺陷细节。

对应代码：Conv2d(3,16,kernel_size=3,padding=1)表示输入3通道、输出16通道，3×3卷积核，其他默认条件下高宽保持不变。
练习：输入[2,3,64,64]经过上面的卷积，输出形状是什么？

[2,16,64,64]。批数2不变，输出通道16；默认步幅1且padding1，高宽保持64。

08 / HANDS-ON

亲手完成一遍训练、验证和测试

下面是一段可独立运行的CPU示例：生成二维数字，训练一个小分类器。它让你理解训练流程，数据不是钢板图片，结果不能用于声称工业检测性能。

步骤：复制代码，保存为新目录下的toy_train.py；在装有PyTorch的环境中运行python .\toy_train.py。程序会在当前目录生成toy_model.pth；若文件已存在会停止，防止覆盖。训练只用180个样本；30个用于验证，30个最终测试。

完整代码：CPU、合成数据、无需下载
from pathlib import Path
import torch
from torch import nn
from torch.utils.data import DataLoader, TensorDataset

# 先检查目标文件，避免重复运行时覆盖已有权重
checkpoint = Path("toy_model.pth")
if checkpoint.exists():
    raise FileExistsError("toy_model.pth已存在；请换一个新目录")

# 1. 固定随机种子，生成教学用数据，不是工业图片
torch.manual_seed(42)
torch.set_num_threads(1)
g = torch.Generator().manual_seed(42)
x = torch.randn(240, 2, generator=g)
noise = 0.25 * torch.randn(240, generator=g)
y = (x[:, 0] + 0.8 * x[:, 1] + noise > 0).long()
order = torch.randperm(240, generator=g)
train_id, val_id, test_id = order[:180], order[180:210], order[210:]

train_data = TensorDataset(x[train_id], y[train_id])
train_loader = DataLoader(train_data, batch_size=20,
                          shuffle=True, num_workers=0)

# 2. 输入2个数；输出2个类别的原始分数（logits）
model = nn.Sequential(nn.Linear(2, 16), nn.ReLU(), nn.Linear(16, 2))
loss_fn = nn.CrossEntropyLoss()
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)

def accuracy(features, labels):
    model.eval()
    with torch.no_grad():
        logits = model(features)
        predicted = logits.argmax(dim=1)
        return (predicted == labels).float().mean().item()

# 3. 一批训练：清梯度 → 前向 → loss → 反向 → 更新
for epoch in range(30):
    model.train()
    total_loss, seen = 0.0, 0
    for features, labels in train_loader:
        optimizer.zero_grad()
        logits = model(features)
        loss = loss_fn(logits, labels)
        loss.backward()
        optimizer.step()
        total_loss += loss.item() * len(labels)
        seen += len(labels)
    if (epoch + 1) % 10 == 0:
        print(f"epoch={epoch+1}, loss={total_loss/seen:.4f}, "
              f"val_acc={accuracy(x[val_id], y[val_id]):.3f}")

# 4. 训练设置事先固定；测试集只在结束后评价一次
test_acc = accuracy(x[test_id], y[test_id])
print(f"test_acc={test_acc:.3f}  (教学合成数据)")

# 5. 保存参数，然后建立同结构模型重新加载
with checkpoint.open("xb") as file:
    torch.save(model.state_dict(), file)
reloaded = nn.Sequential(nn.Linear(2, 16), nn.ReLU(), nn.Linear(16, 2))
with checkpoint.open("rb") as file:
    reloaded.load_state_dict(torch.load(file, map_location="cpu",
                                        weights_only=True))
model.eval()
reloaded.eval()
with torch.no_grad():
    assert torch.allclose(model(x[test_id]), reloaded(x[test_id]))
print("保存与重载：相同输入输出一致")
逐行对照：TensorDataset把输入和标签配对；DataLoader按批提供训练数据；CrossEntropyLoss接收原始logits和整数类别标签；argmax选分数最高的类别。保存的只是参数，重新加载时必须重建相同结构。

该示例使用PyTorch 2.5.1在本机CPU验证；不同版本或平台的输出可能略有差异。它展示固定流程，不代表其他机器或GPU的实验已完成。

练习1：240个样本怎样分为训练、验证、测试？

先打乱索引，再按180、30、30分割；三组索引不重叠。

练习2：为什么不在每一轮用测试结果挑模型？

测试集用于方案锁定后的评价；反复根据测试结果选设置，会让它参与开发并造成偏乐观。

09 / YOLO

把缺陷放进框：检测的输入和输出

目标检测要同时回答“是什么”和“在哪里”。模型输出候选框、类别和分数；后处理会筛选候选框，常用NMS减少重复框。

在一种常见YOLO标签格式中，一行是类别 x中心 y中心 宽 高，四个坐标按图片宽高归一化。例如320×320图片中：0 0.5 0.5 0.2 0.4表示类别0、中心(160,160)、宽64、高128，对应左上(128,96)、右下(192,224)。其他数据格式可能不同，要检查实际数据转换代码。

IoU是两个区域交集面积除以并集面积。它用来衡量预测框和真实框的重叠程度；NMS也会用某种重叠规则去除重复候选。框显示分数阈值和评价时的IoU匹配门槛是不同参数。

实际数据可以从你现有的NEU-DET项目开始。先打开图片与标注，确认类别、坐标、图片尺寸，再查看预测图。原始标注到YOLO格式有转换过程，不要假定所有原始数据已经是YOLO文本格式。
练习：两个2×2框面积各为4，交集面积为1，IoU是多少？

并集=4+4−1=7，所以IoU=1/7≈0.143。

10 / METRICS

误报、漏检和mAP怎么理解？

以一件工件一个最终判断为例：TP是缺陷件正确检出；FN是缺陷件漏检；FP是正常件误报；TN是正常件正确放行。

Precision = TP / (TP + FP) 报警中有多少是真的 Recall = TP / (TP + FN) 缺陷件找到了多少 FPR = FP / (FP + TN) 正常件被误报的比例

若TP=8、FP=2、FN=2、TN=8，则Precision=80%、Recall=80%、FPR=20%。分母不同，所以这三个值回答不同问题。分母为0时要明确标注未定义或采用约定，不能随意解释。

检测AP概括某一类的精确率—召回率表现，mAP是多个类别AP的汇总。mAP@0.5与mAP@0.5:0.95有不同的框匹配IoU口径。AUROC则概括异常与正常分数在不同阈值下的排序表现；一个固定阈值下的误报、漏检仍需单独报告。

若数据集没有独立正常工件图，就不能凭缺陷图片推算正常工件误报率。100个正常样本也不足以稳定估计0.1%的极低误报率。
练习：10件缺陷找出8件，同时10件正常里误报2件。Recall和FPR是多少？

Recall=8/10=80%，FPR=2/10=20%。

11 / ANOMALY

没有很多缺陷样本，怎样学习正常外观？

正常样本异常检测先学习合格工件的特征，再判断新图是否偏离正常模式。常见方法有正常特征库、教师—学生特征差和特征重建。它减少部分缺陷标注需求，但不能保证识别所有未知缺陷；真实测试仍需要相应标签。

把教师和学生想成两套特征提取器

教师使用已有训练得到的知识；学生在正常图上学习模仿教师。测试时计算对应位置的特征差，差异较大的地方可能被标为异常。例如先将两个特征向量单位化，再计算1 − 余弦相似度。将不同位置的得分画出来，就得到异常热图。

LKDF-AD使用预训练教师和轻学生，以多尺度特征差进行异常评分。测试时教师与学生都运行；统计部署成本时，两者都要计入。EfficientAD使用轻量教师—学生结构并结合全局分支；它是另一套方法，训练数据和评价条件需各自记录。

少样本要说明少的是哪一部分。例如“4-shot正常训练”表示某类别用4张正常训练图；若另用20张正常图校准阈值，要同时报告这20张。预训练教师也包含先前数据中学到的信息。

练习：一张正常图换了更暗的灯，异常分数升高，能直接断定工件有缺陷吗？

不能。模型分数可能受照明变化影响。应检查真实工件、正常样本分数分布和改变照明的对照结果。

12 / EXPERIMENT

怎样让一个实验能回答问题？

先写一个可以观察的问题，再确定对照和评价方式。示例问题：同一异常模型在图片变暗时，原有阈值下误报会怎样变化？

要素本例如何固定
模型同一个已训练检查点、相同预处理。
开发用独立正常开发图选择一次阈值。
测试数据使用与开发集分开的正常工件图和缺陷工件图，并确认真实标签；两类分别统计样本数。
测试条件每张测试图分别保留原图，并生成数字亮度×0.8、×0.6的版本。
评价同一阈值下，各条件用正常图计算FPR、用缺陷图计算Recall；另报AUROC、样本数与失败图。若缺少某一类，就不能计算依赖该类的指标。

三个版本来自同一张原图，是配对数据，不能当作三个独立工件。电脑调暗只能说明该数字扰动下的表现；真实曝光、噪声、反光和相机差异需要单独采集验证。

每次记录：问题、数据清单、随机种子、代码/模型版本、实际参数、训练步数、硬件、评价条件和失败样例。单次结果适合流程检查；重复多个种子和批次，有助于观察波动。

练习：新方法训练100轮，对照方法只训练20轮，涨点能完全归因于新方法吗？

不能。训练预算可能影响结果；应补充预算可比的对照，并记录训练与推理成本。

13 / COMPRESSION

模型怎样变轻，效果怎样验证？

结构化剪枝实际删除部分通道等结构，依赖它的后续层也可能要同步调整；再通过训练恢复性能。
知识蒸馏训练学生学习教师的输出或特征。要确认推理阶段教师是否仍存在。
量化用较低精度近似数值，例如INT8。校准范围不合适可能放大误差或造成截断。
真实测速参数量、MAC和毫秒延迟是不同量；推理加速需要在目标硬件上测。

例：把0.26近似到0.1间隔的刻度，可能得到0.3，误差0.04。这只是直觉例子；真实量化要考虑尺度、零点、截断范围及实际算子。训练后量化常称PTQ，训练中模拟量化影响称QAT。

你的NEU-DET已有工程做过三种子对照：未剪枝基线mAP50为73.40%±0.50，轻度剪枝后微调为72.59%±0.36；320×320，最终FP32评价。这里是既有日志中的结果，不是本教程新训练，也不能推断RK3568速度。

练习：为什么需要“未剪枝但继续训练相同时间”的对照？

额外训练本身也可能改变精度。匹配训练预算有助于分清恢复来自训练还是结构变化。

14 / DEPLOYMENT

把模型放到设备上，需要验证什么？

CPU是通用处理器，GPU善于并行计算，NPU针对神经网络运算做加速。相同模型在不同设备上的结果和速度受软件、算子、精度、输入形状与内存等影响。

PyTorch→ONNX→RKNN转换→目标板运行→后处理

ONNX是常见模型交换格式，RKNN是Rockchip工具链使用的模型格式。转换前后用同一输入检查输入颜色、布局、缩放和输出，再检查板上哪些算子实际运行在哪里。工具声明支持某平台，并不保证任意模型或任意形状都能成功部署。

测量时分别记录：模型前向；包含前后处理的离线图片流程；真实相机采集到最终判定的完整流程。固定设备、输入和预热，并说明FP32/FP16/INT8等请求及实际执行精度；不要将GPU或其他板卡的时间写成RK3568实测。

练习：ONNX导出成功，是否意味着已完成RK3568部署？

还需要RKNN转换、板端运行和输出一致性、精度与时间等检查；导出成功只证明前一环节完成。

15 / READING

读论文和代码时，先抓住什么？

  1. 问题：作者想改善什么实际困难？
  2. 输入与输出：模型看什么，给出什么结果，需要哪些标签？
  3. 方法：先用一句话解释，再沿方法图看数据流。
  4. 证据：看数据集、评价指标、输入尺寸、硬件和对照组。
  5. 限制：哪些条件与你不同？哪些部分可以先复现？

第一遍读摘要、问题图、方法图和主结果表；第二遍追训练设置与消融；第三遍再读关键代码或公式。引用的数据要回到原论文的表格和条件核对。

遇到报错，从哪里查？

现象先检查
找不到文件打印实际路径、当前工作目录和文件是否存在。
找不到模块确认当前使用哪个Python环境，以及该环境是否装有所需包。
形状不匹配打印输入、标签和模型输出的shape与dtype。
显存不足查看输入尺寸、batch和其他占用；更改设置后记录对照条件。
loss不下降先查数据/标签、输出形状、loss计算和学习率，不预先假定某个原因。

在你的现有工程中，先观察一组预测，再读结果与代码。打开5个实验的详细说明；打开论文阅读卡片。

练习：两个论文的mAP和FPS都写在摘要里，可以直接比较谁更好吗？

要先看任务、数据集和划分、指标、输入、硬件、精度及计时范围。条件不同，不能直接作为公平排名。
